# FBX runtime plugin

AvaFbx imports FBX geometry and skin weights using ufbx v0.21.3. The triangle fixtures exercise mesh and skin import. The project uses the MIT option for ufbx. [Upstream source](https://github.com/ufbx/ufbx/tree/v0.21.3)

[Current native build instructions](https://github.com/matsuvr/AvaAvaDance/blob/main/Native/README.md)
