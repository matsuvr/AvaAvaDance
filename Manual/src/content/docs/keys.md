title: ショートカット早見表
description: Windows版のキー割り当てを、ポーズ、再生、キー編集、視点の操作別に調べられます。
---

以下は起動時のワークスペースで、キーを変更していない場合の割り当てです。「＋」は同時に押す意味です。数値や名前を入力した後は、ビューポートかタイムラインをクリックしてから操作してください。

## ポーズと視点

| やりたいこと | キー | 操作する場所・条件 |
| --- | --- | --- |
| 選択／移動／回転ツールに切り替える | **Q** ／ **W** ／ **E** | Maya 配列。操作したいボーンを選ぶ |
| 現在の姿勢をキーに登録する | **S** または **Enter** | S は Maya 配列。現在のフレームに登録 |
| 選んだ対象／全体を画面に収める | **F** ／ **A** | Maya 配列。ビューポートで操作 |
| 選択キー／全キーを表示範囲に収める | **F** ／ **A** | Maya 配列。タイムラインで操作 |
| ワイヤーフレーム／通常表示にする | **4** ／ **5** | Maya 配列。ビューポートで操作 |
| 右／上／正面から見る | **F1** ／ **F2** ／ **F3** | Shift を加えると左／下／背面 |
| 移動・回転の軸を全体／ローカルで切り替える | **G** | ローカルでは選択対象の向きに軸がそろう |
| ボーンマーカー／ポーズハンドルの表示を切り替える | **C** ／ **X** | ビューポートで表示を確認 |
| モデルを半透明にする・戻す | **V** | モデルを表示して操作 |

## 再生と移動

| やりたいこと | キー |
| --- | --- |
| 再生／停止 | **P** |
| 先頭のフレームに戻る | **Home** |
| 1フレーム戻る／進む | **←** ／ **→** |
| 現在のポーズを保って1フレーム移動する | **Shift ＋ ←** ／ **Shift ＋ →** |
| 前／次の登録キーへ移動する | **Ctrl ＋ ←** ／ **Ctrl ＋ →** |
| 前／次のトラックを選ぶ | **↑** ／ **↓** |
| 次／前の編集対象に切り替える | **Tab** ／ **Shift ＋ Tab** |
| 現在位置にブックマークを付ける・外す | **Ctrl ＋ M** |
| 前／次のブックマークへ移動する | **Ctrl ＋ ,** ／ **Ctrl ＋ .** |

## キー編集と作品の管理

| やりたいこと | キー |
| --- | --- |
| 作品を新規作成／開く／保存する | **Ctrl ＋ N** ／ **Ctrl ＋ O** ／ **Ctrl ＋ S** |
| 元に戻す／やり直す | **Ctrl ＋ Z** ／ **Ctrl ＋ Y** |
| 選択キーを切り取る／コピーする | **Ctrl ＋ X** ／ **Ctrl ＋ C** |
| 現在位置に貼り付ける／左右を反転して貼り付ける | **Ctrl ＋ V** ／ **Ctrl ＋ W** |
| 選択キーを削除する | **Delete** |
| 選択行にフレーム列を挿入する／列を削除する | **I** ／ **K** |
| ボーンとキーを全選択する／ボーンだけを全選択する | **Ctrl ＋ A** ／ **Shift ＋ A** |

## 割り当てを確認・変更する

「ウィンドウ」→「キー設定…」を開きます。「キーマップ」は初期設定の **Maya** と **従来互換** から選べます。たとえば従来互換では **W** がポーズの左右反転、**E** がポーズの初期化、**S** が未登録ボーンの選択です。従来互換でキーを登録するときは **Enter** を使います。

特定の場所だけで使うキーは、対象をビューポートまたはタイムラインに絞って割り当てます。同じキーでも、どちらをクリックしてから押したかで操作が変わります。
