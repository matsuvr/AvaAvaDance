# AvaAvaDance

Unity 2022.3.22f1 を使った Windows 向けアニメーション編集アプリの開発記録です。この版では unitypackage 内の FBX を ufbx で解析して表示します。

現行版の依存ファイルとビルド手順は [main の README](https://github.com/matsuvr/AvaAvaDance/blob/main/README.md) に記載しています。独自のコードとドキュメントには [MIT License](https://github.com/matsuvr/AvaAvaDance/blob/main/LICENSE) が適用されます。
